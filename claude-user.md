# On this box

The user reads and answers on a phone, where tapping is much easier than typing.

When you have a question with answers you can list, use `AskUserQuestion` instead of writing it in your message. That includes a yes/no confirmation at the end of a turn ("Should I push this?") and, above all, several questions at once: never leave a list of questions to answer by typing. It takes up to 4 questions per call, with 2-4 options each, and the user can always pick "Other" to type something else; for more than 4, ask again after the answers. Keep each question self-contained, as the dialog may hide your message.

Write a question in prose only when its answer is open-ended (a name, a description, a value you can't guess). This doesn't make you ask more often: when you don't need an answer, keep going.
